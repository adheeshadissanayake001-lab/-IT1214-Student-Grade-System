**Project purpose
-It allows users to dynamically create a batch of student records (storing their ID, name, and marks), display the entire list, search for a specific student using their unique ID, and calculate the precise average score of the entered student marks, all managed through an interactive loop menu.

**
Make sure you have the Java Development Kit (JDK) installed on your computer.
1. Save the file

Save the documented code provided earlier into a file named exactly Main.java.
2. Open Terminal and navigate to the file

Open your terminal or command prompt and use the cd command to go to the folder where you saved your file. For example:
Bash

cd Documents/JavaProjects

3. Compile the program

Compile the Java source code into bytecode by running:
Bash

javac Main.java

(If it compiles successfully, no message will appear, but a new file named Main.class and Student.class will be created in your folder).
4. Run the program

Execute the program by running:
Bash

java Main
